## Reporting a Vulnerability

Security is paramount in data and financial systems. If you discover a vulnerability or potential data exposure in RevenueOS:

1. **Do not open a public issue.**
2. Report the vulnerability privately via GitHub Security Advisories or email the maintainer at `25sarvesh2005@gmail.com`.
3. Provide detailed steps to reproduce the issue, including environment configurations and sample queries if applicable.

We will acknowledge receipt within 48 hours and work with you to remediate the vulnerability responsibly.
